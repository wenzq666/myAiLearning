# 银发小篮球：精简 WPF 版

完整解压 ZIP 后双击 SilverBasketballPet.exe。关闭 Codex 不影响此程序。无需 Python、联网或管理员权限，使用 Windows 自带 .NET Framework 4.x / WPF。

左键按住时播放跳跃动作；向左拖动时向左跑，向右拖动时向右跑，松手后恢复拖动前的动作。拖动过程中动画连续播放；暂停状态下拖动仍有动作，松手后恢复暂停。双击挥手，右键切换 9 种动作、调整大小、暂停、切换置顶或退出。也可以通过任务栏菜单关闭窗口，或激活窗口后按 Esc 退出。每次启动默认回到主屏右下角，不保存设置。重复启动会打开多个窗口。

更新时先从旧桌宠的右键菜单退出，再解压并启动新版。2.1 版通过 WPF 鼠标捕获处理拖动，未增加底层系统接口或额外权限。

## 实现范围

这是重新编写的 WPF 程序，使用标准窗口和图片控件。源码不包含 P/Invoke、进程启动、网络请求、注册表读写、文件释放、开机启动、计划任务或安全软件配置修改。动画 PNG 直接内嵌并加载至内存。程序不写入配置文件，不需要安装。

压缩包包含完整源码 Pet.cs、权限清单 app.manifest、构建脚本 build.ps1 和原始动画 sprites.png。权限清单为 asInvoker（普通用户权限）。程序没有混淆、加壳或密码保护；SHA256.txt 用于校验包内文件一致性，不是安全认证。
