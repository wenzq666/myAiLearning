# 银发小篮球 · 独立桌宠

请先将 ZIP 完整解压到普通文件夹，再启动程序，不要在压缩包内直接运行。

此版本为未签名的本地编译程序，已通过编译，但尚未完成桌面运行验证。此前生成的 EXE 消失，原因尚未确认；重新打包不表示已经排除安全软件报毒。如果收到安全提示，请保留威胁名称和检测记录以便复核，不要关闭防护或添加排除项。压缩包无密码，包含可审查的完整源码和素材。

双击 `SilverBasketballPet.exe` 启动。图片和动画已经内嵌，只复制这一个 EXE 也能运行；无需 Python、联网或启动 Codex。适用于带 .NET Framework 4.x 的 Windows 10/11。

- 左键按住宠物拖动；位置和大小会自动保存。
- 双击宠物挥手；默认待机会偶尔挥手、跳跃。
- 右键宠物或任务栏通知区域的图标，可切换动作、暂停、调整大小、找回宠物和退出。
- 如通知区域未显示图标，打开任务栏的隐藏图标列表。
- 同一 Windows 会话仅运行一个实例，重复双击不会生成多个宠物。
- 关闭 Codex 不影响此程序；关机、注销或点击“退出桌宠”才会结束它。

可选开机启动：按 Win+R，输入 `shell:startup`，把此 EXE 的快捷方式放进打开的文件夹。删除该快捷方式即可取消。本程序不会自动设置开机启动。

程序设置保存在 `%LOCALAPPDATA%\SilverBasketballPet\settings.txt`。删除 EXE 即可移除程序，设置文件可以另行删除。

源码为 `Pet.cs`，运行 `build.ps1` 可重新编译；`sprites.png` 是原宠物的完整透明动画图集。9 组动作沿用原来的帧数与时长；16 个方向帧保留在资源中，目前不自动跟随鼠标。
